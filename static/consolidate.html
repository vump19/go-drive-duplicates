문서 통합
대시보드 폴더 비교 폴더 분석

문서 통합은 Google Drive 폴더 내 텍스트 파일들을 비교하고, 중복을 제거한 뒤 하나의 Markdown 파일로 통합하는 도구입니다.

사용 방법:

  • 통합할 파일이 있는 Google Drive 폴더 URL을 입력합니다.
  • 파일 확장자 필터로 대상 파일을 선택합니다 (기본: 모든 텍스트 파일).
  • 문서 통합 시작을 클릭하면 파일을 분석하고 통합합니다.

옵션:

  • 하위 폴더 포함: 하위 폴더의 파일도 포함
  • 결과 파일 최대 크기: 초과 시 여러 파일로 분할
  • 파일 확장자 필터: 특정 확장자만 선택하여 통합

통합 대상 폴더

이 크기를 초과하면 여러 파일로 분할됩니다.
