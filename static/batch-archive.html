폴더 일괄 아카이브
대시보드 폴더 다운로드 폴더 비교

일괄 아카이브는 여러 Google Drive 폴더를 순차적으로 ZIP 압축하여 Drive에 업로드하고, 원본 폴더를 정리하는 도구입니다.

사용 방법:

  • 아카이브할 폴더 URL을 목록에 추가합니다. (여러 개 가능)
  • 하위 폴더 불러오기로 특정 폴더의 하위 폴더를 자동 추가할 수도 있습니다.
  • 일괄 아카이브 시작을 클릭하면 각 폴더를 순차적으로 처리합니다.

처리 흐름: 다운로드 → ZIP 생성 → Drive 업로드 → 원본 휴지통 이동

옵션:

  • ZIP 파일명 형식: 폴더명, 날짜 등 조합 선택
  • 업로드 위치: 상위 폴더(기본) 또는 지정 폴더
  • 삭제 방식: 휴지통 이동 또는 완전 삭제

부모 폴더에서 불러오기
