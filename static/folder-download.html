폴더 다운로드
대시보드 폴더 비교 일괄 아카이브

폴더 다운로드는 Google Drive 폴더를 ZIP 파일로 묶어 내 컴퓨터로 다운로드하는 도구입니다.

사용 방법:

  • Google Drive 폴더 URL 또는 ID를 입력합니다.
  • 다운로드 준비 버튼을 클릭하면 폴더 내 파일을 스캔합니다.
  • 스캔 완료 후 ZIP 파일 다운로드가 시작됩니다.

옵션:

  • 하위 폴더 포함: 하위 폴더의 파일도 함께 다운로드
  • Google Docs 건너뛰기: Google Docs/Sheets/Slides 등 직접 다운로드 불가능한 파일 제외
