폴더 비교 및 정리
대시보드 폴더 분석 파일 탐색기

폴더 비교는 두 개의 Google Drive 폴더를 비교하여 중복 파일을 찾고, 정리할 수 있는 도구입니다.

사용 방법:

  • 폴더 비교 탭: 기준 폴더와 대상 폴더의 URL을 입력하고 비교를 시작합니다. 중복 파일은 선택적으로 휴지통으로 이동할 수 있습니다.
  • 폴더 내 중복 검색 탭: 하나의 폴더 내에서 중복 파일을 찾습니다. 하위 폴더를 포함하여 검색할 수 있습니다.

주요 기능:

  • 해시 기반 정확한 중복 검출 (SHA-256)
  • 비중복 파일을 기준 폴더로 이동
  • 검색 결과에서 파일 경로 확인 및 Google Drive 직접 링크
  • 이전 비교 결과 자동 복원
