폴더 분석
대시보드 폴더 비교 파일 탐색기

폴더 분석은 Google Drive 폴더의 구조를 분석하고, 빈 폴더를 찾아 정리하는 도구입니다.

사용 방법:

  • 폴더 구조 분석: 폴더 URL을 입력하면 하위 폴더 구조, 크기, 파일 수를 트리 형태로 표시합니다. 빈 폴더를 발견하면 선택적으로 휴지통으로 이동할 수 있습니다.
  • 특정 폴더명 검색: 특정 이름의 폴더(예: .svn, node_modules)를 검색하여 일괄 정리합니다.

옵션:

  • 제외 패턴: 분석에서 제외할 폴더명을 쉼표로 구분하여 입력
  • 빠른 검색: 폴더 크기 계산을 생략하여 검색 속도 향상
